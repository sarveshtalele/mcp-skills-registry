# Factory — Governed Engineering skills

A skill suite for modernizing legacy systems under governance, from the
*Governed Engineering Factory* blueprint:

| Skill | Purpose | Output |
|-------|---------|--------|
| `legacy-discovery` | Reverse-engineer a legacy app | spec + architecture + inventory |
| `topology-planning` | Define the target architecture | migration plan + ADRs |
| `task-decomposition` | Turn a spec into a backlog | `tasks.yaml` |
| `ui-modernization` | Plan legacy UI → React | component plan + scaffolds |
| `test-generation` | Generate a test strategy | test plan + stubs |
| `spec-governance` | Validate compliance | audit report (pass/fail) |

Flow: **legacy-discovery → topology-planning → task-decomposition → ui-modernization → test-generation → spec-governance**.
