# Speckit — Spec-Driven Development skills

A toolkit of SDD skills inspired by [GitHub Spec Kit](https://github.com/github/spec-kit).
Use them in any MCP client to drive a project from idea → spec → plan → tasks,
each step producing a structured artifact you can commit and refine.

| Skill | Produces | From |
|-------|----------|------|
| `speckit-constitution` | `constitution.md` | project principles |
| `speckit-specify` | `spec.md` | a feature description |
| `speckit-plan` | `plan.md` | a spec summary + stack |
| `speckit-tasks` | `tasks.md` | a plan summary |

Typical flow: **constitution → specify → plan → tasks**.
